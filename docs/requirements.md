# 已确认需求

需求访谈已完成，本文包含首版基线及后续确认的显式主机 ID、sudo 扩展。实现与验证状态见 README。

## 产品与平台

- 目标为 OpenCode 2 TUI 插件，接口核查基线是 2.0.32。
- 首版正式支持 Windows、macOS 本机连接 Linux 远端；两种本机平台均纳入验证。
- 支持多台有名称的主机、密码认证、私钥认证及私钥口令。
- 主机名称唯一；配置使用固定 ID，改名不改变已有会话引用的配置身份。
- 支持 ProxyJump，跳板机和目标主机分别配置认证方式。
- 首版支持标准 SSH 的多级跳转，以及普通密码、密钥和仅要求登录密码的交互式认证。
- 扫码、动态验证码及登录后菜单式堡垒机认证属于后续扩展。
- 远端使用已有 SSH 服务及所需子系统，不安装插件辅助程序。
- 产品交互由连接管理、状态侧栏及模型工具组成。

## TUI

- `/ssh` 提供主机配置的添加、编辑、删除和连接测试。
- 地址、用户名、认证和跳板等连接相关配置变更在下次连接时生效；已有连接保留建立时的配置快照，并显示需要重连才能使用新配置。
- 改名立即更新显示；仍有会话使用连接时，删除主机配置返回“主机正在使用”。
- 右侧栏显示每台主机的名称、连接状态及独立的远程工作目录；不显示当前目标标识。
- 点击主机的菜单仅包含：连接、测试连接、断开连接。
- 工作目录通过 `ssh_set_workspace` 更新，成功后同步到侧栏。
- 原生 `@` 远程文件补全已移出需求。

## 显式主机与独立工作目录

- 移除当前目标及默认主机概念；除 `ssh_list_hosts` 外，每个 `ssh_*` 工具的首参数为必填 `hostId`，使用发现工具返回的稳定 ID。
- 每个 OpenCode 会话分别保存各主机的连接和工作目录，允许同时操作多台主机。
- 首次连接后从远端登录用户的家目录开始，侧栏可以显示为 `~`。
- `ssh_set_workspace` 可以建立指定主机的连接并修改其工作目录，不进行当前目标选择。
- 修改前校验目录；失败时保留该主机原工作目录。
- 所有普通工具必须明确指定主机 ID，省略或传入名称均不接受。
- 远程相对路径基于对应主机在当前会话中的工作目录；本地相对路径基于会话的本地目录。
- 单条 shell 命令中的临时 `cd` 不改变持续使用的工作目录。
- 工具执行开始时固定本次主机及目录，之后的目录变化不改变已开始的操作；修改一台主机目录不影响其他主机。
- 子代理继承创建时各主机的目录快照，之后父子会话互不跟随。

## 会话隔离与权限

- 侧栏连接状态按当前会话展示。
- 主动断开连接及 `ssh_reset_connection` 只影响当前会话，不中断其他会话对同一主机的使用。
- 插件工具显式接入 OpenCode 权限检查，按执行代理及会话规则授权。
- Plan / Explore 保留主机查询、目录列举、文件读取、搜索及指定主机目录设置能力。
- 只读代理不提供任意远程 shell 执行、写入、上传及下载工具；相关操作由具有相应权限的代理执行。

## 模型工具

| 工具 | 职责 |
| --- | --- |
| `ssh_list_hosts` | 列出已配置主机及 ID、各主机的连接状态和工作目录 |
| `ssh_set_workspace` | 修改指定主机在本会话中的工作目录 |
| `ssh_shell_exec` | 执行远程命令并返回输出和退出状态 |
| `ssh_list_directory` | 列举远程目录 |
| `ssh_read_file` | 读取远程文本文件，支持按行读取 |
| `ssh_write_file` | 写入远程文件 |
| `ssh_grep` | 搜索远程文件内容 |
| `ssh_glob` | 按路径或文件名模式查找远程文件 |
| `ssh_mkdir` | 创建远程目录 |
| `ssh_delete` | 删除远程文件或目录 |
| `ssh_move` | 移动或重命名远程文件、目录 |
| `ssh_upload_file` | 将本地文件上传到远程路径 |
| `ssh_download_file` | 将远程文件下载到本地路径 |
| `ssh_reset_connection` | 重建异常连接 |

参考项目的 13 个工具包含镜像同步与回推。此处将对应能力改为明确的文件下载、上传，并增加每台主机的工作目录设置工具，共 14 个。

## 凭据

- 主机配置长期保存。
- 密码和私钥口令提供“记住凭据”选项；未选择时仅在本次 OpenCode 进程运行期间保存在内存，不因主动断开连接而清除。
- 连接、各主机工作目录和临时凭据均由 OpenCode 后台服务进程持有。仅关闭并重新打开 TUI 时，后台服务中的状态可以继续存在；后台服务退出或重启后清空。
- 选择记住的凭据在本机加密保存；具体存储机制待跨平台接口核查后确定。
- 已记住的凭据按当前设备及操作系统用户保存，不主动跨设备同步；迁移主机信息后重新录入凭据。
- 系统凭据保存失败时明确反馈，用户可以选择仅本次使用，不回退到明文保存。
- 私钥配置保存文件路径。

## 主机身份

- 目标主机及每一级跳板机采用 accept-new 策略：首次连接记录服务器公钥指纹，后续连接必须匹配。
- 指纹变化时报错，明确更新对应信任记录后才可重连。
- 信任记录由插件独立持久化保存。

## 断开与恢复

- 主动断开后，普通工具不自动恢复该连接。
- 点击连接或明确通过 `ssh_set_workspace` 指定主机可以重新连接。
- 网络异常断线后，后续操作可以尝试恢复连接并重新校验工作目录。
- 执行中断线时，对无法确认执行结果的命令返回“执行结果未知”，不自动重放命令。
- 连接重置不承诺终止所有远端进程。
- OpenCode 进程重启后不自动连接，不保留各主机上次的工作目录；重新连接从远端家目录开始。

## 命令与文件传输

- 后续确认的 sudo 扩展：`ssh_shell_exec` 增加默认 `false` 的 `sudo` 参数，显式将整个命令以 root 执行；保持原始命令权限检查并显示提权执行身份。
- sudo 密码通过 TUI 输入或明确确认复用当前主机的 SSH 密码；独立缓存、默认仅进程内保留，主动选择记住后在本机加密保存。不得在工具参数、命令文本或返回结果中传递密码。
- 免密 sudo 和有效认证缓存不重复询问；认证输入与命令 `stdin` 分离。认证失败可以在原 sudo 进程中重新输入，但不得自动提权重跑普通失败命令，或重放结果未知的命令。

- 首版命令同步执行并等待结果，默认超时 120 秒，支持显式延长或关闭超时。
- 超时或取消时停止等待，并尽力终止本次前台命令；仅在收到明确退出结果时报告已结束，否则报告终止状态未确认。
- 已自行脱离的后台进程不承诺随前台命令取消而退出。
- 后台任务管理属于后续扩展。
- 首版上传下载按单文件处理，支持二进制和大文件，使用流式传输。
- 分别检测 SSH 命令执行及 SFTP 能力；上传下载以 SFTP 为前提，SFTP 不可用时明确返回原因，并保留可用的命令执行能力。
- 多个文件可分别调用工具；目录可先打包再传输，递归目录传输属于后续扩展。
- 上传、下载或写文件时，目标已存在则默认返回冲突；显式 `overwrite: true` 才覆盖。
- `ssh_move` 的目标已存在时，同样需要显式 `overwrite: true`。
- `ssh_delete` 删除非空目录时，需要显式 `recursive: true`。
- 写入、上传和移动的父目录不存在时返回错误，由 `ssh_mkdir` 创建。
- `ssh_mkdir` 通过显式 `parents: true` 允许创建多级目录。
- 覆盖写入尽量先写临时文件，再替换目标；失败时保留原文件。不同远端能力下的具体保证待实现验证。
